  {
    "type": "minecraft:constant",

FIX 2 — Complex random_patch files (194 files)

CONTEXT: 194 configured_feature files still contain minecraft:random_patch.
These are NOT simple patch features — they are complex features (tree selectors,
column features, tubeworms, giant groundsels) that use random_patch as a wrapper.

MANDATORY: Before touching ANY file, read it and identify the inner feature type
inside config.feature.feature.

RULE:
  If inner feature type is "minecraft:simple_block" → convert using standard pattern
  If inner feature type is anything else (random_selector, block_column, tree,
  simple_random_selector, or a string reference) → the random_patch wrapper needs
  to be REMOVED and replaced with the inner feature directly, NOT converted to simple_block.

PATTERN FOR UNWRAPPING (non-simple_block inner features):

BEFORE (random_patch wrapping a tree selector):
{
  "type": "minecraft:random_patch",
  "config": {
    "tries": 1,
    "xspread": 0,
    "yspread": 0,
    "zspread": 0,
    "feature": {
      "feature": {
        "type": "minecraft:random_selector",
        "config": { ... }
      },
      "placement": [ ... ]
    }
  }
}

AFTER (unwrap — the inner placed_feature becomes the file content):
{
  "feature": {
    "type": "minecraft:random_selector",
    "config": { ... }
  },
  "placement": [ ... existing placement from config.feature.placement ... ]
}

NOTE: The outer random_patch tries/xspread values become count + random_offset
placement modifiers prepended to the placement array:
  { "type": "minecraft:count", "count": <tries> }
  {
    "type": "minecraft:random_offset",
    "xz_spread": { "type": "minecraft:constant", "value": 0 },
    "y_spread": { "type": "minecraft:constant", "value": 0 }
  }
  ... then the existing placement modifiers ...

VERIFY each converted file against ./26.1.2/ to confirm structure is valid.
If uncertain about any file → mark ⚠️ UNCERTAIN and skip.
