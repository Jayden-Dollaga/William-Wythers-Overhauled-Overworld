# WWOO Java Port — 26.1.2

William Wythers' Overhauled Overworld ported to Java Edition 26.1.2.

## Structure

| Folder              | Contents                                      |
|---------------------|-----------------------------------------------|
| `src/`              | Live datapack (`pack.mcmeta` + `data/`)       |
| `tools/`            | Python fix / analyze / verify scripts         |
| `docs/blueprints/`  | Blueprint Prompt files for Gemini pipeline    |
| `docs/reports/`     | Completion & fix reports                      |
| `docs/scans/`       | Spyglass sweep scan outputs                   |
| `docs/notes/`       | Misc notes and migration docs                 |
| `logs/`             | Spyglass error exports, audit JSON            |
| `backups/`          | Old versions and snapshots (git-ignored)      |
