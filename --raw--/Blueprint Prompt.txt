WHAT CHANGED: minecraft:random_patch, minecraft:flower, and minecraft:flower_no_bonemeal
have been REMOVED entirely in 26.1.2. They are not renamed — they do not exist.
Patches are now expressed as:
  - A configured_feature using minecraft:simple_block (just the block to place)
  - A placed_feature using count + random_offset placement modifiers

MANDATORY: Before fixing ANY file in this category, open these vanilla reference files:
  ./26.1.2/data/minecraft/worldgen/configured_feature/grass.json
  ./26.1.2/data/minecraft/worldgen/placed_feature/patch_grass_normal.json
These show the exact new format. Use them as your template.

FIX FOR configured_feature files (type = minecraft:random_patch):
  Step 1 — Extract the block state from config.feature.feature.config.to_place
  Step 2 — Rewrite the entire file as:
  {
    "type": "minecraft:simple_block",
    "config": {
      "to_place": <extracted block state provider>
    }
  }
  Step 3 — Find the matching placed_feature file (same name, placed_feature dir)
  Step 4 — Rewrite its placement array using count + random_offset pattern
           (copy from ./26.1.2/data/minecraft/worldgen/placed_feature/patch_grass_normal.json
            and substitute the tries/xspread/yspread values from the old config)

EXCEPTION — Complex inner features (random_selector, block_column, tree):
  If the inner feature inside random_patch is NOT a simple_block
  (i.e. it's a random_selector, tree, block_column, or string reference),
  do NOT convert to simple_block. Mark as ⚠️ UNCERTAIN and skip.
  These require manual restructuring.

EXCEPTION — Placed_feature references:
  Files in placed_feature/ that REFERENCE a configured_feature by ID string
  (e.g. "feature": "minecraft:patch_large_fern") — do not convert the placed_feature.
  Instead update the reference string to the new configured_feature ID.
  Check ./26.1.2/data/minecraft/worldgen/placed_feature/ for the correct new ID.
  If not found in vanilla, mark ⚠️ UNCERTAIN.

AFFECTED FILES: All configured_feature files where "type": "minecraft:random_patch"
  Run: grep -rl '"type": "minecraft:random_patch"' data/ --include="*.json"
